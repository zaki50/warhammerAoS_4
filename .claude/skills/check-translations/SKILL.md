# 未使用の訳のチェック

`official_translations/<ファクションslug>.json` と `own_translations/<ファクションslug>.json` の
キー（`unit_names` / `weapon_names` / `ability_names` / `ability_texts`）のうち、md 生成で一度も使われないものを列挙する。
dump.json の更新でユニットや武器・アビリティが消えたり改名されたりすると、訳ファイルにキーだけが
残るので、それを見つけるためのもの。

## 使い方

スクリプト: `scripts/check_translations.py`（Python 3 標準ライブラリのみ）

```bash
CK=.claude/skills/check-translations/scripts/check_translations.py

python3 $CK --dump dump.json          # 列挙のみ（終了コード 0）
python3 $CK --dump dump.json --fail   # 未使用があれば終了コード 1
```

訳フォルダは dump.json と同じディレクトリから探す。ファイルは読むだけで書き換えない。

## 判定

生成規則を複製せず、**実際に全 md をメモリ上で生成して**、照合されたキーを記録する
（ファイルには書かない。数秒かかる）。

- 生成するもの: 全ファクションのウォースクロール（グランドアライアンス含む）、
  全ファクションのファクションルール、全 Spearhead
- 照合の記録: `.claude/skills/_lib/aos_translations.py` の `LOOKUPS`（引こうとしたキー）と
  `SHADOWED`（`ユニット|名前` が当たったため引かれなかった `名前`）

生成側に新しい訳の当て先を足しても、この判定は自動的に追随する。

| 報告 | 意味 | 対処 |
|---|---|---|
| ファイル名に一致するファクションが dump.json に無い | ファクションの改名・統合、またはファイル名の誤り | 正しいスラッグのファイルに移す |
| dump.json にこの名前が無い | 削除・改名 | 改名なら新しい英語名でキーを付け直す。削除ならキーを消す |
| ユニット「X」が dump.json に無い | `X|名前` の X が削除・改名 | 同上 |
| このファクションの md に出ない | 名前はあるが別ファクションのもの（移動、またはファイル違い） | 正しいファクションのファイルに移すか消す |
| このファクションの md で、ユニット「X」にこの名前が出ない | `X|名前` の組み合わせが誤り | ユニットを直すか、名前だけのキーにする |
| 出てくる箇所がすべて、より具体的なキーで上書きされていて使われない | 名前だけのキーがユニット指定のキーに、または `ability_texts` で Spearhead 指定のキーに完全に隠れている | どちらかを消す |
| 公式訳に同じキーがあるので使われない | 独自訳が公式訳に上書きされている | 独自訳側のキーを消す |

- 自動では消さない。改名の場合は新しいキーへの付け直しが必要で、消すと訳が失われるため
- 訳のセクションを増やすときは `_lib/aos_translations.py` の `SECTIONS` と、このスクリプトの
  `known_names()`（そのセクションの名前が dump.json のどのテーブルにあるか）を足す
