## バトル特性


### Court of the Godlings Battle Traits（出典: Army of Renown: Court of the Godlings）

- **The Voice and the Talon**（Passive）
  - 効果: The friendly **Synessa** and **Dexcessa** have the **TWIN** keyword.
- **The More Glorious Slaughter**（Once Per Turn, Start of Any Turn）
  - 宣言: If a friendly **TWIN** destroyed an enemy unit in the previous turn and the other did not, pick the one that did not to use this ability.
  - 効果: For the rest of the turn, add 1 to hit rolls for combat attacks made by units in the regiment of the unit using this ability.
- **The Longer Shadow**（Your Hero Phase）
  - 宣言: If a friendly **TWIN** is contesting an objective you control and the other is not, pick the one that is not to use this ability.
  - 効果: Until the start of your next turn, while the unit using this ability is contesting an objective you control, add 5 to the control scores of units in its regiment.
- **The Grander Visage**（Once Per Turn (Army), Any Hero Phase）
  - 宣言: If either friendly **TWIN** is damaged, pick the one with fewer or no damage points to use this ability.
  - 効果: For the rest of the turn, the unit using this ability has **WARD (4+)**.
- **The Swifter Surge**（Once Per Turn (Army), Any Charge Phase）
  - 宣言: If a friendly **TWIN** charged in the previous turn and the other did not, pick the one that did not to use this ability.
  - 効果: For the rest of the phase, when making charge rolls for units in the regiment of the unit using this ability, add 1 to the number of dice rolled, to a maximum of 3, then remove 1 dice of your choice and use the remaining dice as the charge roll.
- **The More Cunning Ruse**（Once Per Turn (Army), End of Any Turn）
  - 宣言: If both friendly **TWINS** are within 12" of and visible to each other, pick one of them to use this ability.
  - 効果: Remove the unit using this ability from the battlefield and set it up on the battlefield more than 9" from all enemy units.

## 英雄特性


### Court of the Godlings Heroic Trait（出典: Army of Renown: Court of the Godlings）

**HERO** only

- **Tethered to the Twins**（Once Per Battle, Your Hero Phase）
  - 宣言: Pick a friendly **TWIN** that has been destroyed to be the target.
  - 効果: Set up a replacement unit identical to the target within 12" of this unit and more than 9" from all enemy units.

**HERO** only

- **The Triplet Trinket**（Passive）
  - 効果: While a friendly **TWIN** is within 3" of and visible to this unit, subtract 1 from hit rolls for attacks that target that **TWIN** and this unit.
