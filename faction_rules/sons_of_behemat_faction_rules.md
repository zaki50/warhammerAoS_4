## バトル特性


### Sons of Behemat Battle Traits（出典: Destruction Battletome: Sons of Behemat）

Sons of Behemat armies can use the following abilities:

- **Take A Run At It**（Once Per Turn (Army), Your Movement Phase）
  - 宣言: Pick any number of friendly **BIG** or **LITTLE** units to be the targets.
  - 効果: Roll a dice. If the roll is lower than the number of targets picked, this ability has no effect. Otherwise, pick an effect for each target. The effects must be different unless specified otherwise. • Pick an enemy unit in combat with the target and roll a D3. On a 2+, inflict an amount of mortal damage on that enemy unit equal to the roll. You can pick this effect for multiple targets. • The target is **building momentum** for the rest of the turn. • If the target is within 3" of a battlefield edge, remove it from the battlefield and set it up in reserve **beyond the horizon**. • For the rest of the phase, the target can pass through enemy models and terrain features when using **MOVE** abilities as if it had **FLY**.
- **Argy Bargy**（Once Per Turn (Army), Your Charge Phase）
  - 宣言: Pick any number of friendly **BIG** or **LITTLE** units to be the targets.
  - 効果: Roll a dice. If the roll is lower than the number of targets picked, this ability has no effect. Otherwise, pick an effect for each target. The effects must be different unless specified otherwise. • Pick an enemy unit in combat with the target and roll a D3. On a 2+, inflict an amount of mortal damage on that enemy unit equal to the roll. You can pick this effect for multiple targets. • If the target is **building momentum**, it is no longer **building momentum** and is **getting ready** for the rest of the turn instead. • For the rest of the turn, each time the target makes a pile-in move, add 3" to the distance it can move.
- **Wrathful Rampage**（Once Per Turn (Army), Any Combat Phase）
  - 宣言: Pick any number of friendly **SONS OF BEHEMAT** units to be the targets.
  - 効果: Roll a dice. If the roll is lower than the number of targets picked, this ability has no effect. Otherwise, pick an effect for each target. The effects must be different unless specified otherwise. • Pick an enemy unit in combat with the target and roll a D3. On a 2+, inflict an amount of mortal damage on that enemy unit equal to the roll. You can pick this effect for multiple targets. • If the target is **LITTLE** and is **getting ready**, it is no longer **getting ready** and has **STRIKE-FIRST** for the rest of the turn instead. • If the target is **BIG** and is **getting ready**, it is no longer **getting ready**. Instead, either it has **STRIKE-FIRST** for the rest of the turn or it is **prepping the big one** for the rest of the turn.
- **Haring Back**（Once Per Turn (Army), End of Your Turn）
  - 宣言: If a friendly unit is in reserve **beyond the horizon**, you must pick that unit to use this ability.
  - 効果: Set up that unit within 1" of a battlefield edge and more than 9" from all enemy units. If it is not possible to set it up, it wanders off and is automatically destroyed.
- **The Big One**（Once Per Turn (Army), End of Your Turn）
  - 宣言: Pick any number of friendly **BIG** or **LITTLE** units to be the targets.
  - 効果: Roll a dice. If the roll is lower than the number of targets picked, this ability has no effect. Otherwise, pick an effect for each target. The effects must be different unless specified otherwise. • Pick an enemy unit in combat with the target and roll a D3. On a 2+, inflict an amount of mortal damage on that enemy unit equal to the roll. You can pick this effect for multiple targets. • If the target is **prepping the big one**, pick an enemy unit in combat with it and roll any number of dice. If any of the rolls are a 1, the target is no longer **prepping the big one**. Otherwise, add the results together, then inflict an amount of mortal damage on that enemy unit equal to the total.

## バトルフォーメーション


### Big Toes

- **Lofty Louts**（Once Per Battle, Deployment Phase）
  - 宣言: Pick a friendly **Mancrusher Gargant** unit to be the target.
  - 効果: For the rest of the battle, add 1 to hit rolls for combat attacks made by friendly **GARGANT** units while they are wholly within 12" of the target and not wholly within 12" of any friendly **MEGA-GARGANT** units.

### Conquering Stomp

- **Arrogant Big 'Uns**（Passive）
  - 効果: In the first battle round, subtract 1 from hit rolls for combat attacks that target friendly **BIG** and **LITTLE** units that have not charged in the same turn.

### Eager Louts

- **Ten-League Strides**（Passive）
  - 効果: Each time a friendly **BIG** or **LITTLE** unit uses the 'Redeploy' command or the 'Run' ability, if you roll a 1-2 when determining the distance that unit can move, you can use a value of 3 instead.

### Heirs of the Old Ways

- **Brute Spirituality**（Once Per Turn (Army), Your Hero Phase）
  - 宣言: Pick a friendly **BIG** or **LITTLE** unit to use this ability, then pick an enemy **WIZARD** or **PRIEST** within 18" of it to be the target.
  - 効果: Make a rampage roll of D6. If the roll equals or exceeds the target's Control characteristic: • The target has a maximum power level of 1 until the start of your next turn. • All **MANIFESTATIONS** that were summoned by the target are banished and removed from play.

### Looting Leviathans

- **Get To The Goods**（Passive）
  - 効果: Each time a friendly **BIG** or **LITTLE** unit that charged in the same turn makes a pile-in move, that unit can pass across enemy models in non-**MONSTER** units.

### Manskittle Mob

- **Strike! Hur Hur!**（Once Per Turn (Army), Your Shooting Phase）
  - 宣言: Pick up to 2 friendly **MEGA-GARGANT** units within 3" of any terrain features and pick any friendly **GARGANT** units within 3" of any terrain features to be the targets.
  - 効果: Double the Attacks characteristic of each target’s ranged weapons for the rest of the turn. If the target has no ranged weapons, pick an enemy unit within 12" of the target instead and roll a D3. On a 2+, inflict an amount of mortal damage on that enemy unit equal to the roll.

## その他の強化


### Cracked Heels（出典: Scourge of Aqshy: Sons of Behemat）

Cracked Heels are unique enhancements that can be given to **Mancrusher Gargants**.  A unit can only have 1 Cracked Heel.

- **That Boy's not Right**（Your Hero Phase / 10pt）
  - 効果: Roll a dice. On a 5+, this unit can use a Prayer ability from the prayer lore you picked during army composition as if it had **PRIEST (1)**. Instead of making a chanting roll for that prayer, the chanting roll is 5 and cannot be modified.
- **Up For It**（Passive / 10pt）
  - 効果: This unit’s melee weapons have **Charge (+1 Damage)**.
- **Always on Guard**（Passive / 10pt）
  - 効果: This unit has **WARD (5+)** while it is wholly within 12" of and visible to a friendly **BIG** unit.

### Realm-Shaking Rampages（出典: Destruction Battletome: Sons of Behemat）

A Realm-shaking Rampage is a unique enhancement that can be given to non-**UNIQUE** **BIG** units. A unit can only have 1 Realm-shaking Rampage, but, unless specified otherwise, a unit can use multiple **RAMPAGE** abilities in the same turn.

- **Hammer Throw**（Once Per Turn (Army), Your Shooting Phase / 20pt）
  - 宣言: If this unit is not in combat, pick a friendly **Mancrusher Gargant** within its combat range to be the target.
  - 効果: Roll 3D6. On a 4+, remove the target from the battlefield and set it up again wholly within a number of inches of this unit equal to the roll and visible to this unit. It can be set up in combat. The target cannot use **CHARGE** abilities for the rest of the turn. If the target is set up in combat: • Inflict D3 mortal damage on the target. • Inflict 1 mortal damage on each enemy unit in combat with the target. • The target has charged this turn.
- **Earthshaking Roar**（Once Per Turn (Army), Any Combat Phase / 20pt）
  - 宣言: Pick an enemy unit in combat with this unit to be the target.
  - 効果: Make a rampage roll of D6. On a 3+, the target cannot use commands for the rest of the turn.
- **Battered Shrimp**（Once Per Turn (Army), Any Combat Phase / 20pt）
  - 宣言: Pick an enemy non-**MONSTER HERO** in combat with this unit to be the target
  - 効果: Both players roll off. If you win the roll-off, roll off again. Keep rolling off in this way until you lose the roll-off. Then, inflict an amount of mortal damage on the target equal to the number of roll-offs made as part of this ability that you won this turn.
- **Windmill Walloping**（Once Per Turn (Army), Any Combat Phase / 20pt）
  - 宣言: Pick an enemy **MONSTER** or **WAR MACHINE** in combat with this unit to be the target.
  - 効果: Roll a number of dice equal to the target's Health characteristic. Add 1 to each roll for each consecutive turn in which the target was picked to be the target of this ability. For each 6+, allocate 1 mortal damage to the target (ward rolls cannot be made for those damage points).
- **Colossal Slam**（Once Per Turn (Army), Any Combat Phase / 20pt）
  - 宣言: Pick an enemy **MONSTER** or **WAR MACHINE** that has no more than 1 model and is in combat with this unit to be the target.
  - 効果: If 2 or more friendly **BIG** or **LITTLE** units are in combat with the target, apply the effect below. Otherwise, make a rampage roll of D6. Subtract 1 from the roll if the target has a higher Health characteristic than this unit. On a 3+, apply the effect below. Remove the target from the battlefield and set it up again in combat with this unit. Then, inflict D3 mortal damage on the target.
- **Rancid Flatulence**（Once Per Battle (Army), End of Any Turn / 20pt）
  - 効果: For the rest of the turn, enemy units have a maximum control score of 1 while they are in combat with this unit.

## ロア（呪文・祈祷・顕現）


### Brodd's Bellows

- **Rock Bottom**（Your Hero Phase / 詠唱/詠誦値 3）
  - 宣言: Pick a friendly **SONS OF BEHEMAT PRIEST** to chant this prayer, pick a visible friendly **SONS OF BEHEMAT** unit wholly within 12" of them to be the target, then make a chanting roll of D6.
  - 効果: If the chanting roll was 6+, you can pick another eligible unit to be a second target. Until the start of your next turn: •  Ignore the effects of the ‘Battle Damaged’ ability on each target. •  Each target has **WARD (6+)**.
- **The Terrible Toes**（Your Hero Phase / 詠唱/詠誦値 4）
  - 宣言: Pick a friendly **SONS OF BEHEMAT PRIEST** to chant this prayer, pick a visible enemy unit within 18" of them to be the target, then make a chanting roll of D6.
  - 効果: Roll a dice for each model in the target unit. If the chanting roll was 8+, add 1 to the roll. For each 6+, inflict 1 mortal damage on the target. Then, if any enemy models are slain by this ability, halve the target’s Move characteristic until the start of your next turn.
- **Vocal Tectonics**（Your Hero Phase / 詠唱/詠誦値 5）
  - 宣言: Pick a friendly **SONS OF BEHEMAT PRIEST** to chant this prayer, pick a visible enemy unit within 12" of them to be the target, then make a chanting roll of D6.
  - 効果: If the chanting roll was 10+, you can pick another eligible unit to be a second target. Until the start of your next turn, each target has **STRIKE-LAST**.

### Lore of Behemat

- **Energy Surge**（Your Hero Phase / 詠唱/詠誦値 6）
  - 宣言: Pick a friendly **SONS OF BEHEMAT WIZARD** to cast this spell, pick a visible friendly **SONS OF BEHEMAT MONSTER** unit wholly within 12" of them to be the target, then make a casting roll of 2D6.
  - 効果: If the target is **BIG**, add 1 to rampage rolls for it until the start of your next turn. If the target is **LITTLE**, until the start of your next turn, it can use **CHARGE** abilities even if it used a **RUN** ability in the same turn.
- **Thornfang's Wrath**（Your Hero Phase / 詠唱/詠誦値 6）
  - 宣言: Pick a friendly **SONS OF BEHEMAT WIZARD** to cast this spell, pick a visible friendly **SONS OF BEHEMAT MONSTER** unit wholly within 12" of them to be the target, then make a casting roll of 2D6.
  - 効果: The target's melee weapons have **Crit (Mortal)** for the rest of the turn.
- **Pipsqueak Curse**（Your Hero Phase / 詠唱/詠誦値 7）
  - 宣言: Pick a friendly **SONS OF BEHEMAT WIZARD** to cast this spell, pick a visible enemy unit within 18" of them to be the target, then make a casting roll of 2D6.
  - 効果: Subtract 1 from wound rolls for the target's attacks until the start of your next turn.

### Prayers of the World Titan

- **World Titan's Stride**（Your Hero Phase / 詠唱/詠誦値 3）
  - 宣言: Pick a friendly **SONS OF BEHEMAT PRIEST** to chant this prayer, pick a visible friendly **SONS OF BEHEMAT MONSTER** unit wholly within 18" of them to be the target, then make a chanting roll of D6.
  - 効果: For the rest of the turn, add 3" to the target's Move characteristic and models in the target unit can pass across enemy models and terrain features as if it had **FLY**. In addition, if the chanting roll was 6+, for the rest of the turn, each time the target uses the 'Normal Move' or 'Run' ability, after that ability has been resolved, inflict D3 mortal damage on each enemy unit the target passed across as part of that move.
- **Behemat's Vengeance**（Your Hero Phase / 詠唱/詠誦値 4）

  - 効果: If the chanting roll was 8+, you can pick another eligible unit to be a second target. Add 1 to the Attacks characteristic of each target's melee weapons for the rest of the turn.
- **Might of the Earth**（Your Hero Phase / 詠唱/詠誦値 4）
  - 宣言: Pick a friendly **SONS OF BEHEMAT PRIEST** to chant this prayer, pick each friendly **SONS OF BEHEMAT** unit on the battlefield to be the targets, then make a chanting roll of D6.
  - 効果: **Heal (D3)** each target. If the chanting roll was 8+, **Heal (3)** each target instead.
