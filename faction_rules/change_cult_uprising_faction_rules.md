## バトル特性


### Change-Cult Uprising Battle Traits（出典: Army of Renown: Change-Cult Uprising）

- **Silver Simulacrum**（Once Per Battle (Army), Deployment Phase）
  - 効果: If there is a friendly **Argent Shard** on the battlefield, you can set up 1 additional **Argent Shard** on the battlefield. It must be set up wholly within friendly territory and more than 3" from all objectives and other terrain features. **Designer’s Note:** *The original Argent Shard is set up in Step 1 of the deployment phase using the ‘Deploy Faction Terrain’ ability. This ability allows you to set up a second such terrain feature and is used in Step 3 of the deployment phase, after armies have been deployed.*
- **Puppet on a String**（Once Per Turn (Army), Any Hero Phase）
  - 宣言: Pick an enemy **HERO** within 24" of and visible to a friendly **CHANGE-CULT HERO** to be the target.
  - 効果: For the rest of the turn, each time the target uses a **CORE** ability, gain 1 **fate point**. **Designer’s Note:** *You can only gain fate points using this ability and the ‘Spell-eater Pendant’ ability.*
- **Illusory Infiltration**（Once Per Battle (Army), Deployment Phase）
  - 宣言: Pick up to 3 friendly non-reinforced **CHANGE-CULT KAIRIC ACOLYTES** units to be the targets.
  - 効果: Remove the targets from the battlefield and set them up again wholly within 3" of a terrain feature and not in combat.
- **Overtaken by Events**（Once Per Turn (Army), Any Hero Phase）
  - 宣言: Spend 1 **fate point**. Then, pick an enemy unit within 24" of and visible to a friendly **CHANGE‑CULT HERO** to be the target.
  - 効果: The target cannot use commands for the rest of the turn.
- **Seeds of Discord**（Once Per Turn (Army), End of Any Turn）
  - 宣言: Spend 1 **fate point**. Then, pick an enemy model within 24" of and visible to a friendly **CHANGE-CULT HERO** to be the target, then pick another enemy unit within the target’s combat range to be the victim.
  - 効果: Pick 1 of the target’s melee weapons. Immediately resolve combat attacks for the target made with that weapon against the victim.

## 英雄特性


### Change-Cult Uprising Heroic Trait（出典: Army of Renown: Change-Cult Uprising）

**HERO** only

- **Call of Anarchy**（Your Movement Phase / CP 1）
  - 宣言: Pick a terrain feature within 18" of this unit, then pick a friendly non-**HERO CHANGE-CULT** unit that is **masked by illusion** or that has been destroyed to be the target.
  - 効果: If you picked a unit that is **masked by illusion**, set it up wholly within 3" of that terrain feature and more than 6" from all enemy units. If you picked a unit that has been destroyed, set up a replacement unit with half the number of models from the target unit (rounding up) wholly within 3" of that terrain feature and more than 6" from all enemy units. **Designer’s Note:** *Units can be set up in reserve masked by illusion using the Fatemaster’s ‘Long in the Planning’ ability.*
