## 戦闘特性


### Stormcast Eternals Battle Traits（出典: Order Battletome: Stormcast Eternals）

Stormcast Eternals armies can use the following abilities:

- **Scions of the Storm**（Your Movement Phase）
  - 宣言: Pick a friendly **STORMCAST ETERNALS** unit that is **in the** **Celestial Realm**.
  - 効果: Set up that unit anywhere on the battlefield more than 9" from all enemy units.
- **The Celestial Realm**（Deployment Phase）
  - 宣言: If there are more friendly **STORMCAST ETERNALS** units on the battlefield than there are set up in reserve, pick a friendly **STORMCAST ETERNALS** unit that has not been deployed.
  - 効果: Set up that unit in reserve **in the Celestial Realm**. It has now been deployed.
- **Their Finest Hour**（Once Per Turn (Army), Your Hero Phase）
  - 宣言: Pick a friendly **STORMCAST ETERNALS** unit that has not used this ability this battle to use this ability.
  - 効果: For the rest of the turn, add 1 to wound rolls for that unit’s combat attacks and add 1 to save rolls for that unit.
- **Heavens-sent**（Once Per Battle, Your Movement Phase / CP 1）
  - 宣言: Pick a friendly non-**UNIQUE STORMCAST ETERNALS INFANTRY** or **CAVALRY** unit that started the battle with 2 or more models and that has been destroyed to be the target.
  - 効果: Set up a replacement unit with half the number of models from the target unit (rounding up) more than 9" from all enemy units.

## 戦闘陣形


### Lightning Echelon

- **Oncoming Storm**（Once Per Turn (Army), Any Combat Phase）
  - 宣言: Pick a friendly **EXTREMIS CHAMBER** unit that charged this turn.
  - 効果: Roll a dice. On a 3+, that unit has **STRIKE-FIRST** for the rest of the turn.

### Sacrosanct Convocation（Legends）

- **Cycle of the Storm**（Once Per Turn (Army), End of Your Turn）
  - 宣言: Pick a friendly **SACROSANCT CHAMBER** unit that had models slain in this turn to be the target.
  - 効果: Return 1 slain model to the target unit.

### Sentinels of the Bleak Citadels

- **Ancient Aura**（Once Per Turn (Army), Any Hero Phase）
  - 宣言: Pick a friendly **RUINATION CHAMBER** unit.
  - 効果: That unit has **WARD (5+)** for the rest of the turn.

### Thunderhead Host

- **Synchronised Strikes**（Passive）
  - 効果: Add 1 to hit rolls for combat attacks made by friendly **WARRIOR CHAMBER** units while they are wholly within 12" of any friendly non-**HERO** non-**BEAST STORMCAST ETERNALS** units that do not have the **WARRIOR CHAMBER** keyword.

### Vanguard Wing

- **Peerless Manoeuvres**（Once Per Turn (Army), Your Movement Phase）
  - 宣言: Pick a friendly **VANGUARD CHAMBER** unit that did not use a **MOVE** ability this turn and is not in combat.
  - 効果: Roll a dice. On a 3+, remove that unit from the battlefield and set it up again anywhere on the battlefield more than 9" from all enemy units.

## 英雄特性


### Aspects of Azyr（出典: Order Battletome: Stormcast Eternals）

**HERO** only

- **Staunch Defender**（Passive）
  - 効果: While this unit is contesting an objective in friendly territory, add 3 to the control scores of friendly **STORMCAST ETERNALS** units contesting that objective.
- **Shock and Awe**（Passive）
  - 効果: Each time this unit is set up using the 'Scions of the Storm' ability, subtract 1 from hit rolls for attacks that target this unit for the rest of the battle round. In addition, each time a friendly **STORMCAST ETERNALS** unit is set up wholly within 12"of this unit using the 'Scions of the Storm' ability, subtract 1 from hit rolls for attacks that target that unit for the rest of the battle round.
- **Envoy of the Heavens**（Your Hero Phase / 20pt）
  - 宣言: If a friendly **STORMCAST ETERNALS** unit was destroyed in the previous turn, pick a visible friendly **STORMCAST ETERNALS** unit wholly within 12"of this unit to be the target.
  - 効果: The target has **WARD (5+)** until the start of your next turn.

### Stormforged Qualities（出典: Scourge of Ghyran: Stormcast Eternals）

**HERO** only

- **Intense Piety**（Your Hero Phase）
  - 宣言: Pick a visible enemy **PRIEST** or **WIZARD** within 18" of this unit to be the target.
  - 効果: Roll a dice. On a 3+, subtract 1 from casting rolls and chanting rolls for the target until the start of your next turn.
- **Hour of Glory**（Passive）
  - 効果: This unit can be picked to use the ‘Their Finest Hour’ ability even if it has already used it this battle. In addition, when this unit is picked to use the ‘Their Finest Hour’ ability, add 5 to its control score for the rest of the turn.
- **Legendary Tenacity**（Passive）
  - 効果: The first time this unit would be destroyed, before removing it from play, roll a dice. On a 3+, this unit is not destroyed and any remaining damage points inflicted on it have no effect. Then, **Heal (D3)** this unit.

## 神器


### Artefacts of the Tempest（出典: Order Battletome: Stormcast Eternals）

**HERO** only

- **Mirrorshield**（Passive）
  - 効果: This unit cannot be targeted by shooting attacks unless the attacking model is within 9" of it.
- **Quicksilver Draught**（Once Per Battle, Any Combat Phase）
  - 効果: This unit has **STRIKE-FIRST** for the rest of the turn.
- **Null Pendant**（Once Per Battle, End of Any Turn）
  - 宣言: Pick an enemy unit in combat with this unit to be the target.
  - 効果: Subtract 5 from the target’s control score for the rest of the turn.

### Artefacts of the Tempest（出典: Scourge of Aqshy: Stormcast Eternals）

**HERO** only

- **Pennant of Azyrite Majesty**（Start of Any Turn）
  - 宣言: Pick a visible enemy unit within 18" of this unit to be the enemy target, then you can pick a friendly **STORMCAST ETERNALS** unit wholly within 12" of this unit to be the friendly target.
  - 効果: Spend 1 **rage dice**. If your opponent’s **fury level** is lower than yours, they must increase their **fury level** by 1, to a maximum of 7. Then, for the rest of the turn, while it is visible to this unit: • Subtract 1 from casting rolls and chanting rolls for the enemy target. • Add 1 to casting rolls and chanting rolls for the friendly target.
- **Blade of the Six Smiths**（Any Combat Phase）
  - 宣言: Pick 1 of this unit’s non-**Companion** melee weapons to be the target.
  - 効果: For the rest of the turn: • Halve the Attacks characteristic of the target weapon (rounding up). • Double the Damage characteristic of the target weapon. • Attacks made with the target weapon score critical hits on unmodified hit rolls of 3+.
- **Fractured Astral Jewel**（Passive）
  - 効果: If an ability would heal or return any slain models to an enemy unit while it is within 6" of this unit, that ability does not heal any damage points or return any slain models to it.

### Relics of Sigmaron（出典: Scourge of Ghyran: Stormcast Eternals）

**HERO** only

- **Beacon of Azyr**（Once Per Battle, Any Hero Phase）
  - 宣言: Pick a visible friendly **STORMCAST ETERNALS WIZARD** or **PRIEST** wholly within 12" of this unit to be the target.
  - 効果: The next time this turn that the target uses a **PRAYER** or **SPELL** ability, instead of making a casting roll or chanting roll for them, you can use a value of 7 for the roll that cannot be modified. After that ability is resolved, if the target has any ritual points, reset their ritual points total to 0. **Designer’s Note:** *Ritual points apply modifiers so cannot be used with this ability to increase the chanting roll to more than 7.*
- **Sigil of Morrda**（Once Per Turn, Reaction: Opponent declared a command or a **RAMPAGE** ability for a unit in combat with this unit）
  - 効果: Roll a dice. On a 3+, that command or **RAMPAGE** ability has no effect, it still counts as having been used and any command points spent to use that ability are still lost.
- **Banner of Sigmar**（Once Per Battle, Your Hero Phase）
  - 宣言: Pick an objective within 18" of this unit to be the target.
  - 効果: Until the start of your next turn, your opponent cannot control the target objective while they have no units contesting it.

## その他の強化


### Scars of War（出典: Scourge of Aqshy: Stormcast Eternals）

Scars of War are unique enhancements that can be given to non-**HERO** non-**BEAST STORMCAST ETERNALS** units.  A unit can only have 1 Scar of War.

- **Uncaged Lightning**（Passive / 20pt）
  - 効果: Each time an enemy unit in combat with this unit moves or is removed from the battlefield, after that ability has been resolved, if that enemy unit is on the battlefield and not in combat with this unit, inflict D3 mortal damage on that enemy unit.
- **Veterans of Amberstone Watch**（Passive / 10pt）
  - 効果: Enemy units do not have the **STRIKE-FIRST** keyword while they are in combat with this unit. **Designer’s Note:** *Enemy units that have* **STRIKE-LAST** *would still have* **STRIKE-LAST***; they would not be treated as having neither* **STRIKE-FIRST** *nor* **STRIKE-LAST.**
- **Pyrotechnic Souls**（Passive / 10pt）
  - 効果: When this unit is destroyed, gain 3 **rage dice**.

### Prayers of the Stormhosts

- **Healing Storm**（Your Hero Phase / 詠唱/詠誦値 4）
  - 宣言: Pick a friendly **STORMCAST ETERNALS PRIEST** to chant this prayer, pick a visible friendly **STORMCAST ETERNALS** unit wholly within 12" of them to be the target, then make a chanting roll of D6.
  - 効果: **Heal (D3)** the target. If the chanting roll was 8+, **Heal (D3)** each visible friendly **STORMCAST ETERNALS** unit wholly within 12" of the chanter instead.
- **Translocation**（Your Hero Phase / 詠唱/詠誦値 4）
  - 宣言: Pick a friendly **STORMCAST ETERNALS PRIEST** to chant this prayer, pick a visible friendly **STORMCAST ETERNALS** unit wholly within 12" of them to be the target, then make a chanting roll of D6.
  - 効果: Remove the target from the battlefield and set it up again on the battlefield more than 9" from all enemy units. In addition, if the chanting roll was 8+, subtract 1 from hit rolls for attacks that target that unit for the rest of the battle round.
- **Bless Weapons**（Your Hero Phase / 詠唱/詠誦値 6）
  - 宣言: Pick a friendly **STORMCAST ETERNALS PRIEST** to chant this prayer, pick a visible friendly **STORMCAST ETERNALS INFANTRY** unit wholly within 12" of them to be the target, then make a chanting roll of D6.
  - 効果: Add 1 to the Attacks characteristic of the target’s melee weapons until the start of your next turn. If the chanting roll was 12+, this ability affects all visible friendly **STORMCAST ETERNALS** units wholly within 12" of the chanter.
