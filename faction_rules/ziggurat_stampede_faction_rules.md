### Ziggurat Stampede Battle Traits（出典: Army of Renown: Ziggurat Stampede）

- **Let The Realms Tremble**（Passive）
  - 効果: Add **X** to charge rolls for friendly **ZIGGURAT STAMPEDE** units, where **X** is the number of friendly **ZIGGURAT STAMPEDE** units that have already charged this phase.
- **'Break Them, One and All...'**（Passive）
  - 効果: Any number of friendly **ZIGGURAT STAMPEDE** units can use the ‘Power Through’ command in the same turn.
- **Run Roughshod**（Your Movement Phase / CP 1）
  - 宣言: Pick a friendly **ZIGGURAT STAMPEDE** unit in combat to be the target.
  - 効果: For the rest of the turn: •  The target can use **SHOOT** and/or **CHARGE** abilities even if it used a **RETREAT** ability in the same turn. •  No mortal damage is inflicted on the target by **RETREAT** abilities.
