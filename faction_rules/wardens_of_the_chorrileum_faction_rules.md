## バトル特性


### Wardens of the Chorrileum Battle Traits（出典: Army of Renown: Wardens of the Chorrileum）

- **The Ocean Conceals**（Once Per Battle (Army), Deployment Phase）
  - 宣言: This ability must be used to deploy the friendly **CHORRILEUM EIDOLON** instead of the ‘Deploy Unit’ ability or the ‘Deploy Regiment’ ability.
  - 効果: Set up the friendly **CHORRILEUM EIDOLON** in reserve **awaiting a summons**. It has now been deployed.
- **Call Forth the Tsunami**（Once Per Battle (Army), Your Combat Phase）
  - 宣言: You can only use this ability if you have 3 or more **chorrileum spirit points**. Pick a friendly unit **awaiting a summons** to be the target.
  - 効果: Set up the target anywhere on the battlefield. Then, inflict D3 mortal damage on each enemy unit in combat with it.
- **Spirits of the Chorrileum**（Passive）
  - 効果: Each turn, you can gain up to 1 **chorrileum spirit point**. You gain 1 **chorrileum spirit point** the first time 1 of the following occurs in a turn: • You make an unmodified casting roll of 8 or more for a friendly **ISHARANN WIZARD**. • An enemy unit is destroyed while it is within 12" of any friendly **ISHARANN** units. • A friendly unit is destroyed while it is wholly within 12" of any friendly **ISHARANN** units or while it is contesting an objective you control
- **Wrath of Mathlann**（Once Per Turn (Army), Any Combat Phase）
  - 宣言: Pick a friendly **CHORRILEUM EIDOLON** unit that has not used any **RAMPAGE** abilities this turn to use this ability.
  - 効果: That unit can use 2 **FIGHT** abilities this phase. After the first is used, however, that unit has **STRIKE‑LAST** for the rest of the turn. The unit using this ability cannot use any other **RAMPAGE** abilities for the rest of the turn.

  - 効果: While this unit and a friendly **CHORRILEUM NAMARTI** unit are contesting the same objective, this unit has a control score of 10 that cannot be modified.

### Wardens of the Chorrileum Artefact of Power（出典: Army of Renown: Wardens of the Chorrileum）

**HERO** only

- **Ammonite Carnyx**（Once Per Battle, Your Hero Phase）
  - 宣言: Pick a friendly **CHORRILEUM NAMARTI** unit that has been destroyed to be the target.
