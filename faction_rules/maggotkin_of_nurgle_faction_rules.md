## バトル特性


### Maggotkin of Nurgle Battle Traits（出典: Chaos Battletome: Maggotkin of Nurgle）

Maggotkin of Nurgle armies can use the following abilities:

- **Blighted Regrowth**（Your Hero Phase）
  - 宣言: You can use this ability if there are no friendly **Feculent Gnarlmaws** on the battlefield.
  - 効果: Set up a **Feculent Gnarlmaw** on the battlefield wholly within 12" of an objective you control and more than 3" from all enemy units, objectives and other terrain features.
- **Blessed by the Plaguefather**（Once Per Turn (Army), End of Any Turn）
  - 効果: Pick 1 of the following effects: ***Infect:*** Pick an enemy unit within 7" of any friendly Maggotkin of Nurgle units to be the target. You cannot pick a **MANIFESTATION** or terrain feature. • If the target is in combat with any friendly **MAGGOTKIN OF NURGLE** units, it has the **DISEASED** keyword. • If the target is not in combat with any friendly **MAGGOTKIN OF NURGLE** units, roll a dice. On a 4+, the target has the **DISEASED** keyword. ***Spread:*** Pick a **DISEASED** enemy unit to be the target. Each other enemy unit within the target’s combat range, excluding **MANIFESTATIONS** and terrain features, has the **DISEASED** keyword. ***Mutate:*** If all enemy units on the battlefield, excluding **MANIFESTATIONS** and terrain features, have the **DISEASED** keyword, inflict 1 mortal damage on each of them.
- **Wracked with Disease**（Once Per Turn (Army), End of Any Turn）
  - 宣言: Pick each **DISEASED** enemy unit to be the targets.
  - 効果: Inflict D3 mortal damage on each target.
- **Ceaseless Infectors**（Once Per Turn (Army), End of Any Turn）
  - 宣言: Pick an enemy unit that was in combat with a friendly **ROTBRINGERS** unit that was destroyed this turn to be the target. You cannot pick a **MANIFESTATION** or terrain feature.
  - 効果: Roll a dice. On a 3+, the target has the **DISEASED** keyword.
- **Burst Pustules**（Passive）
  - 効果: Each time a **DISEASED** enemy unit is destroyed, before the last model in the unit is removed from play, roll a dice. On a 3+, pick another enemy unit within 9" of that model to be the target. You cannot pick a **MANIFESTATION** or terrain feature. The target has the **DISEASED** keyword.
- **Desperate Remedies**（Passive）
  - 効果: If an ability would heal or return slain models to a **DISEASED** enemy unit, that ability does not heal or return any slain models to it. Instead, it no longer has the **DISEASED** keyword.

### Affliction Cyst

- **Filth-laden Daemonic Blooms**（Passive）
  - 効果: Each time you make a run roll for a friendly non-**MONSTER MAGGOTKIN OF NURGLE DAEMON** unit, you can change that roll to a 4.

### Nurgle's Menagerie

- **Denizens of the Garden**（Passive）
  - 効果: **Companion** weapons used by friendly **MAGGOTKIN OF NURGLE** units have **Crit (2 Hits)**.

### Plague Cyst

- **Vectors of Contagion**（Passive）
  - 効果: Add 5 to the control scores of friendly non-**HERO ROTBRINGERS** units while they are wholly within 12" of any friendly **MAGGOTKIN OF NURGLE DAEMON** units.

### Tallyband of Nurgle

- **Plague Progenitor**（Once Per Battle (Army), Deployment Phase）
  - 宣言: Pick an enemy unit on the battlefield to be the **plague progenitor** for the rest of the battle. You cannot pick a **MANIFESTATION** or terrain feature.
  - 効果: Roll 2D3. On a 6, or if the roll equals or exceeds the **plague progenitor**’s Health characteristic, it has the **DISEASED** keyword. In the first battle round, if an ability would heal or return any slain models to a **DISEASED plague progenitor**, that ability does not heal any damage points or return any slain models to it. Each time the **plague progenitor** is picked to be the target of the ‘Spread’ effect of the ‘Blessed by the Plaguefather’ ability, inflict D3 mortal damage on each other enemy unit within its combat range, excluding **MANIFESTATIONS** and terrain features, in addition to the effect of that ability.

**HERO** only

  - 効果: If this unit is in combat with a **Diseased** enemy unit, **Heal (D3)** this unit.

  - 宣言: Pick a visible friendly non-**HERO MAGGOTKIN OF NURGLE** unit that is wholly within 12" of this unit to be the target.
  - 効果: Roll a dice. On a 3+, add 1 to the Attacks characteristic of the target’s melee weapons for the rest of the turn.

  - 宣言: Pick an enemy unit in combat with this unit to be the target.
  - 効果: You and your opponent must roll off. If your roll is higher, pick 1 of the following effects to apply for the rest of the turn: • Ignore positive modifiers to save rolls for the target. • Subtract 1 from ward rolls for the target.

### Grandfather's Gifts（出典: Scourge of Ghyran: Maggotkin of Nurgle）

**HERO** only

- **Unctuous Preacher**（Passive）
  - 効果: If this unit is not a **PRIEST**, it has **PRIEST (1)**. If this unit is already a **PRIEST**, add 1 to chanting rolls for this unit.
- **Corpulent Avalanche**（Any Charge Phase）
  - 宣言: If this unit charged this turn, pick a visible enemy unit within 1" of it to be the target.
  - 効果: Roll a number of dice equal to this unit’s Move characteristic. For each 3+, inflict 1 mortal damage on the target. If any damage points were allocated to the target by this ability, this unit can move 2D3". It can move through the combat ranges of enemy units but must end that move in combat with the units it was already in combat with at the start of the move.
- **Living Plague**（Once Per Battle, Any Combat Phase）
  - 宣言: If this unit charged this turn, pick an enemy unit in combat with it to be the target.
  - 効果: The target has the **DISEASED** keyword.

## その他の強化


### Plaguefather's Poxes（出典: Scourge of Aqshy: Maggotkin of Nurgle）

Plaguefather’s Poxes are unique enhancements that can be given to non-**HERO MAGGOTKIN OF NURGLE** units. A unit can only have 1 Plaguefather’s Pox.

- **Snuggling Sickness**（Any Hero Phase / 10pt）
  - 宣言: Pick an enemy unit in combat with this unit to be the target.
  - 効果: For the rest of the turn: • Each time the target uses a **RETREAT** ability, if it is in combat with this unit, roll 2D6 as a reaction and add the target’s Control characteristic to the roll. On an 8+, that **RETREAT** ability has no effect. • The target cannot be removed from the battlefield by an ability that would allow it to be set up elsewhere on the battlefield or in reserve.
- **Chuckling Murrain**（Passive / 10pt）
  - 効果: Your opponent must spend 1 additional **rage dice** for a unit to use the ‘Eruption of Fury’ ability while it is in combat with this unit. When resolving the damage sequence for enemy units in combat with this unit, each time your opponent would spend **rage dice** as part of the ‘Fight Through the Pain’ ability, they must spend 1 additional **rage dice**. In both cases, that additional dice does not count towards the number of **rage dice** spent for the purposes of the ability.
- **The Weeping Flux**（Passive / 10pt）
  - 効果: Each time a model in this unit is slain by a combat attack, roll a number of dice equal to this unit’s Health characteristic. For each 6, inflict 1 mortal damage on the attacking unit.
