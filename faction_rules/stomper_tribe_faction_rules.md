## バトル特性


### Stomper Tribe Battle Traits（出典: Army of Renown: Stomper Tribe）

- **Stomp! Stomp! Stomp! Stomp!**（Once Per Turn (Army), Any Combat Phase）
  - 宣言: Pick an enemy unit in combat with a friendly **STOMPER TRIBE** unit to be the target.
  - 効果: Roll a dice. Add 1 to the roll for each friendly **STOMPER TRIBE** model in combat with the target. On a 5+: • The target has **STRIKE-LAST** for the rest of the turn. • Inflict 3 mortal damage on the target.
- **Get In There, You Runts!**（Once Per Turn (Army), Any Charge Phase）
  - 宣言: Pick a friendly **LITTLE** unit that is within a friendly **BIG** unit's combat range, visible to it and not in combat to be the target.
  - 効果: You can re-roll charge rolls for the target for the rest of the turn, and the target has **FLY** for the rest of the phase.
- **Grab Those Rocks and Chuck 'Em!**（Once Per Battle (Army), Any Shooting Phase）
  - 宣言: Pick each friendly **LITTLE** unit wholly within 18" of and visible to a friendly **BIG** unit and not in combat to be the targets.
  - 効果: Add 1 to the Attacks characteristic of each target's ranged weapons for the rest of the turn.
- **Gettin' Stuck In**（Once Per Turn (Army), Any Combat Phase）
  - 宣言: Pick a friendly **STOMPER TRIBE** unit in combat to be the target.
  - 効果: If the target is **LITTLE,** pick a model in the target unit. Add 1 to the Damage characteristic of that model's melee weapons for the rest of the turn. If the target is **BIG,** add 1 to the Rend characteristic of its melee weapons for the rest of the turn.
- **Stompin' About**（Once Per Turn (Army), Your Movement Phase）
  - 宣言: Pick a friendly LITTLE unit wholly within 12" of and visible to a friendly **BIG** unit to use this ability.
  - 効果: That **LITTLE** unit can move D6+3". It can pass through the combat ranges of enemy units but cannot end that move in combat. Then, you can inflict D3 mortal damage on each enemy unit that has a lower Health characteristic than that **LITTLE** unit and that it passed across during that move.

  - 効果: Add 2 to the Attacks characteristic of this unit's **Almighty Stomp** if it did not use a **FIGHT** ability in the previous turn.

## その他の強化


### Little Toes（出典: Army of Renown: Stomper Tribe）

Little Toes are unique enhancements that can be given to **Mancrusher Gargants.** A unit can only have 1 Little Toe.

- **Future Stomper**（Passive）
  - 効果: This unit can use the 'Power Through' command even if it has not charged this turn.
- **Carefully Watched**（Reaction: You declared a FIGHT ability for this unit）
  - 効果: Pick a friendly **BIG** unit that has not used a **FIGHT** ability this turn and is wholly within 12" of this unit to be the target. The target can be picked to use a **FIGHT** ability immediately after the **FIGHT** ability used by this unit has been resolved. Add 1 to hit rolls for attacks made by this unit and the target for the rest of the turn.
- **Little Hopper**（Passive）
  - 効果: This unit can be picked to use the 'Stompin' About' ability even if it is not wholly within 12" of and visible to a friendly **BIG** unit.
- **Keen Bean**（Passive）
  - 効果: While this unit is wholly within 12" of and visible to a friendly **BIG** unit, it can use **CHARGE** abilities even if it used a **RUN** ability in the same turn.
