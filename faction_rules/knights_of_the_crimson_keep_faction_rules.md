## バトル特性


### Knights of the Crimson Keep Battle Traits（出典: Army of Renown: Knights of the Crimson Keep）

- **The Crimson Keep**（Deployment Phase）
  - 宣言: Pick a friendly **CRIMSON KEEP** unit that has not been deployed.
  - 効果: Set up that unit in reserve **in the Crimson Keep**. It has now been deployed. You cannot set up more friendly units **in the Crimson Keep** than there are on the battlefield.
- **Blood Rampage**（Once Per Turn (Army), Any Combat Phase）
  - 宣言: Pick a friendly **CRIMSON KEEP MONSTER** that is in combat and has not used any **RAMPAGE** abilities this turn to use this ability, then pick an enemy unit in combat with it to be the target.
  - 効果: This unit can make a move of 2D6". It must end that move in combat with the target unit. Then, roll a dice. If the roll exceeds the target unit’s Health characteristic, 1 model in the target unit is slain. After this ability has been resolved, this unit cannot use **RAMPAGE** abilities for the rest of the turn.
- **Carve A Bloody Path**（Your Charge Phase / CP 1）
  - 宣言: Pick a friendly **Blood Knights** unit that is in combat to use this ability.
  - 効果: That unit can use a **CHARGE** ability even though it is in combat and even if it has already used a **CHARGE** ability this turn.
- **From A Quarter Unseen**（Once Per Battle (Army), Any Movement Phase）
  - 宣言: You cannot use this ability in the first battle round. Pick each friendly unit that is **in the Crimson Keep** to be the targets.
  - 効果: Set up each target wholly within 9" of the battlefield edge and more than 9" from all enemy units. If you set up any units using this ability in the third or a subsequent battle round, do not spend any command points when using the ‘Carve a Bloody Path’ command this turn.

## 英雄特性


### Knights of the Crimson Keep Heroic Trait（出典: Army of Renown: Knights of the Crimson Keep）

- **Immortal Dedication**（Any Combat Phase）
  - 効果: This unit receives D3 **martial prowess tokens**. Each **martial prowess token** can be spent to do 1 of the following: • Re-roll a hit roll for this unit. • Re-roll a wound roll for this unit. • Re-roll a save roll for this unit. At the start of the next turn, remove all this unit’s **martial prowess tokens**.
