## バトル特性


### Ruination Brotherhood Battle Traits（出典: Army of Renown: Ruination Brotherhood）

- **Entropic Screech**（Once Per Turn (Army), Any Combat Phase）
  - 宣言: Pick a friendly **RUINATION CHAMBER MONSTER** that has not used any **RAMPAGE** abilities this turn to use this ability. Then, pick up to 3 enemy units in combat with it to be the targets.
  - 効果: Roll a D3 for each target. On a 2+, inflict an amount of mortal damage on the target equal to the roll. The unit using this ability cannot use any more **RAMPAGE** abilities for the rest of the turn.
- **Hallowed Presence**（Passive）
  - 効果: While friendly **WARRIOR CHAMBER** units are wholly within 12" of any friendly **RUINATION CHAMBER** units, those friendly **WARRIOR CHAMBER** units have **WARD (6+)**.
- **Ancient Aura**（Once Per Turn (Army) Any Hero Phase）
  - 宣言: Pick a friendly **RUINATION CHAMBER** unit.
  - 効果: That unit has **WARD (5+)** for the rest of the turn.
- **Temper the Flaw**（Once Per Turn (Army), End of Any Turn）
  - 宣言: You must use this ability at the end of each turn. Each friendly non-**HERO RUINATION CHAMBER** unit that used a **FIGHT** ability this turn is a target.
  - 効果: For each target, pick 1 of the following effects: • ***Guided:*** If the target is wholly within 12" of any friendly **RUINATION CHAMBER HEROES**, return 1 slain model to it. • ***Tormented:*** If the target is not wholly within 12" of any friendly **RUINATIONS CHAMBER HEROES**, it becomes tormented until the end of the next turn. While a unit is tormented, add 1 to the Attacks characteristic of its melee weapons but it cannot contest objectives or use commands.

## ロア（呪文・祈祷・顕現）


### Ruination Brotherhood Prayer Lore

- **Murderous Flock**（Your Hero Phase / 詠唱/詠誦値 4）
  - 宣言: Pick a friendly **RUINATION BROTHERHOOD PRIEST** to chant this prayer, pick a visible enemy unit within 12" of them to be the target, then make a chanting roll of D6.
  - 効果: Roll a dice for each model in the target unit. For each 5+, inflict 1 mortal damage on the target unit. If the chanting roll was 10+, inflict 1 mortal damage on the target unit for each 4+ instead.
- **Raven's Flight**（Your Hero Phase / 詠唱/詠誦値 4）
  - 宣言: Pick a friendly **RUINATION BROTHERHOOD PRIEST** to chant this prayer, pick a visible friendly unit wholly within 12" of them to be the target, then make a chanting roll of D6.
  - 効果: Add 2" to the target’s Move characteristic for the rest of the turn. If the chanting roll was 8+, in addition, for the rest of the turn, the target can use **CHARGE** abilities even if they have used a **RUN** ability in the same turn.
- **Morrda's Embrace**（Your Hero Phase / 詠唱/詠誦値 5）
  - 宣言: Pick a friendly **RUINATION BROTHERHOOD PRIEST** to chant this prayer, pick a visible enemy unit within 18" of them to be the target, then make a chanting roll of D6.
  - 効果: Roll a dice. If the roll exceeds the target's Health characteristic, 1 model in the target unit is slain. If the chanting roll was 10+, roll 2D6 instead.
